# 💾 MYSPACE GLITCH — Old-Web Shader Graveyard

An organized, **non-destructive** collection of early-internet, MySpace/Angelfire/GeoCities, bling-web, glitchcore, VHS/CRT, signal rot, datamosh, low-res pixels, and UI-chaos art. Animated HTML sketches and their raw JS live side-by-side. Nothing was removed from the source folders.

**121 animated HTML/JavaScript shader pairs**, **13 legacy standalone HTML exports** and thumbnail previews where available.

Open an `.html` file to view its original self-contained sketch; `.js` is the source to modify or remix. The techniques and ingredients are inventoried in [catalog.json](./catalog.json).

## Selection rules

- Start with the complete `by_math` signal/VHS/CRT/glitch, dither/halftone, and typography categories.
- Add strongly relevant designs from other math categories: old-web, Y2K, pixel-locking, feedback corruption, datamosh, chroma-codec and screen-techniques.
- Preserve variations as named—underscore, hyphen and timestamp variants may be visibly different.
- Do not mistake general-purpose noise, unrelated fractals or all retrofuturism for actual MySpace/Web 1.0 design.
- Original source files are untouched. No Netlify actions, app settings changes or deployment requests.
- This is file and source-code curation; individual visual output and mobile performance have not been re-tested.
