# 🧵 SEWING — Psychedelic textile shaders and source collection

A non-destructive collection of sewing, lace, crochet, embroidery, woven fabric, tartan, damask, brocade and fiber-themed shaders and demo code drawn from Merry's archives.

**Included:** 24 complete animated HTML/JavaScript sketch pairs; 16 GLSL shader snippets; 13 sewing/weaving HTML demos and JS utilities; 5 alternate legacy exports; and visual thumbnails where available.

## Quilt situation

**No independently quilt-named shader was identified** in `shaderslop_designs`, `repo_script_js5_code`, `shader_files_2`, or `shaderfiles3`. The tartan, fabric, stitch and weave shaders provide ingredients for making a quilt shader, but are not misrepresented as quilt generators. The separate [`quilting_patterns`](https://github.com/merrypranxter/quilting_patterns) repository is currently empty.

## Provenance and limits

- Source files were copied, never removed or altered. The original directories and app configuration remain unchanged.
- HTML sketches from `by_math` are self-contained exports; sources are retained separately.
- `catalog.json` records original paths and source repos.
- Visual appearance and iPhone rendering have not been re-tested in this curation step.
- No deploy job or Netlify API call was made for this operation.
